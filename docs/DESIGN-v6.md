## 2 判断：现在缺的不是好看，是「活着」

1. **首屏是静态摘要**：五个事实都对，但看不出它在变。评审要的 hero moment 是「正在工作的仪表」，不是「一分钟前的报表」。
2. **交互只有开关和跳页**：所有 App 都有开关。Leapin 有「一条路」这个独占隐喻，却只用来展示，没用来操作。
3. **四块各说各话**：资源是列表、监控是表格、agent 是输入框、设置是表单。没有一种统一的「块」语法，页面之间不像一个产品。

## 3 方向：把窗口变成一台可以上手拨的仪器

一句话：**状态不是读出来的，是拨出来的。**

三条硬规则（违反即返工）：

1. **变化必须可见**：任何与网络有关的主数字，1 秒内至少动一次；静止的数字必须是「真的没变」，不是「没采样」。
2. **重要动作优先用手，不优先用菜单**：出口、布局、时间、资源都能拖；菜单只做兜底。
3. **全产品一种块语法**：卡（Card）、脊（Spine）、河（River）、草稿（Draft）。任何页面只能由这四种块组成。

## 4 六个签名交互

每个交互都必须给出：触发 → 过程 → 结束 → 空/错/离线 → 无障碍替代。

### 4.1 RouteScrubber · 拖出口

- **触发**：在「一条路」的出口节点上按住。
- **过程**：节点变成滑块，沿轨道跟手；轨道下方浮出候选出口（当前策略组成员），刻度吸附；松手前只预览，不生效。
- **结束**：吸附到最近刻度 → 松手 → 调用 `select(group:outbound:)` → 节点回弹并显示「已切到 X · 撤销」6 秒。
- **空/错/离线**：未配对时轨道只有「直连」一个刻度，拖动给出阻尼和「未配对」提示；请求失败则回弹到原刻度并显示原因。
- **无障碍**：节点是 `accessibilityAdjustableAction`，上下滑切换候选；VoiceOver 读「出口，当前 X，可调整」。

### 4.2 Compose · 编排模式

- **触发**：长按任意卡片 0.45 秒（或页头「编排」）。
- **过程**：所有卡片缩成同尺寸缩略图并轻微抬起；拖动换位，右下角 S/M/L 改跨度，左上角眼睛隐藏；顶部出现「完成 / 恢复默认」。
- **结束**：点「完成」写入 `UserDefaults`（键 `lp.deck.v6`），下次启动按同一顺序渲染。
- **空/错/离线**：隐藏到只剩一张时禁止再隐藏，提示「至少留一张」；布局解码失败则回落默认顺序。
- **无障碍**：编排模式提供「上移/下移/改尺寸/隐藏」四个 context menu 动作。

### 4.3 Time River · 时间河

- **触发**：首屏与连接页顶部常驻；在河上横向拖动。
- **过程**：60 根 1 秒柱（上行向上、下行向下），拖动时冻结并显示该秒的「连接数 / 速率 / 命中出口」；右侧出现「回到现在」。
- **结束**：点「回到现在」或松手 3 秒后自动回到实时。
- **空/错/离线**：没有采样时画一条平线并写「刚开始，还没有波形」；引擎停止时河变灰、不滚动。
- **无障碍**：河是一个 adjustable 元素，左右滑逐秒回看；读数用文本同步。

### 4.4 Spine Shelf · 书脊资源库

- **触发**：资源页默认视图；左右滑。
- **过程**：配置/订阅以竖排书脊展示，脊上是名字、来源、规则数；点一下「抽出」成一张详情卡（封面＋目录＋体检结果）；长按拖动两条脊相叠 → 比较差异。
- **结束**：详情卡上「设为当前 / 导出 / 删除」。
- **空/错/离线**：没有资源时给一条空书脊和「导入第一份配置」。
- **无障碍**：书脊是按钮，详情卡是 sheet；比较动作放在 context menu。

### 4.5 Agent Draft · 草稿行

- **触发**：任意页面底部常驻一行「告诉我要改什么」；输入 `/` 调出命令。
- **过程**：输入自然语言 → 就地生成一张「变更卡」（做什么 / 影响哪条规则 / 可撤销），不跳页、不开聊天窗。
- **结束**：`应用` → 执行并留回执；`放弃` → 卡片收起。
- **空/错/离线**：无法解析时给出三个可点的示例，不写「我不明白」；离线时禁用并说明原因。
- **无障碍**：草稿行是文本框＋发送按钮，变更卡是普通按钮组。

### 4.6 MenuBar Live Capsule · 菜单栏活体

- **触发**：常驻菜单栏；点图标展开。
- **过程**：图标内嵌两条 2px 速率微条（上行/下行），不打开也能看出有没有流量；下拉第一段仍是「一条路」，但节点可拖；hover 某段展开详情，不跳页。
- **结束**：点外部收起；拖动结果与窗口内同步。
- **空/错/离线**：未接管时图标灰、微条为空；错误时图标角标一个朱红点。
- **无障碍**：菜单项提供「切换出口」子菜单，等价于拖动。

## 5 令牌增量（叠在 v5 上）

| Token | 值 | 用途 |
| --- | --- | --- |
| `deck` | paper 提亮 2% / ink 提亮 2% | 编排底板 |
| `ghost` | 墨 6% / 白 8% | 拖影与占位 |
| `riverLive` | accent | 实时柱 |
| `riverPast` | 墨 22% / 白 24% | 历史柱 |
| `spine` | 纸色＋发丝线＋左侧 3px 墨条 | 书脊 |

书脊实现说明（本轮）：不新增令牌。「墨条」用 `LP.text` 而不是 `LP.ink`——`ink` 在深色模式里几乎是纸色本身，墨条会整条消失；`text` 在浅色是近黑、深色是米白，两个模式都成立。规则数只分四档厚度（46/54/62/70），不做连续映射。

- 尺寸：卡片跨度 S=1、M=2、L=4（4 列网格）；间距只用 4/8/12/16/24。
- 动效：拖起 120ms、吸附 180ms、编排进入 240ms；`accessibilityReduceMotion` 时全部改为淡入淡出。
- 颜色：状态色只出现在点、线、窄条；不做大面积填充。
