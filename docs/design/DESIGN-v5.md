# 设计复盘与 v5 迭代方案

> 2026-11-23 · lead（PM）· 基于当前实现截图、`Design/Theme.swift` 与两轮 M2 页面改造的复盘。
> 这不是又一份"视觉规范"；它先回答**为什么现在丑**，再给一套能落地的构图与裁决规则。

## 0 一句话结论

现在的丑不是配色问题，是**没有构图**：每屏有 5–8 个同等重量的区块、三条互相打架的轴线、9–10pt 的字和三种材质叠加。v5 只做一件事：**每屏只允许一个焦点，其余全部退到纸面。**

## 1 复盘：丑在哪（有证据）

对照 `docs/shots/m2/t06-shot-gowhere.png` 与 `t06-shot-why.png`：

1. **轴线打架**：页标题左对齐、tab 居中悬浮、工具条右对齐。眼睛没有一条可以顺着走的线。
2. **两种卡片语言并存**：浅色描边卡（场景 6 张）+ 深色实心大卡（线路与订阅、常用书签）+ 橙色/黑色 CTA。三者重量相当，谁也不是主角。
3. **字号过小**：`DESIGN.md` 自己规定"7–10pt 标签"；截图里说明文字、分组、按钮都在 9–10pt。1440 屏上像仪表说明书，不像给人用的工具。
4. **mono 泛滥**：数字用 mono 是对的；但说明、按钮、导航也在用 mono/大字距，数据和文字没有分层。
5. **选中态读作警告**：侧栏选中行是浅朱红底（`LP.accentSoft`）+ 左条，与 danger 同色系。用户第一眼以为"这行出错了"。
6. **空态与主操作抢**：为什么页空态里一个橙色大按钮，工具条还有"启动代理/观测"，页面级 CTA 三重并存。
7. **层级靠颜色不靠构图**：所有区块同宽、同边框、同圆角；没有留白节奏，也没有"先看什么、再看什么"的顺序。
8. **三种材质叠加**：`LPGlass`（Liquid Glass）+ `cardTint`（白 34%）+ `panel`（纸）+ 深色大卡。玻璃本来是"浮起来"的隐喻，内容区也铺，就全部变平。
9. **品牌只有颜色**：Editorial Instrument 只落在朱红和 mono 上；没有形状、构图或一个记得住的组件（地震仪只待在抓包页）。
10. **每页自造组件**：panel / tile / rail / strip / 卡 / 行，各页拼法不同，系统感来自 token，不来自构图。

## 2 根因

- **从功能列表直接堆模块**：先问"这页要放什么"，没先问"这页只回答哪一个问题"。
- **设计系统停在 token 层**：有颜色/字号/圆角，没有**布局模板、模块预算、构图规则**。
- **竞品学习停在功能对照**：拆了"它们有什么"，没拆"它们的眼睛先落在哪、留白怎么给"。
- **验收标准是"有没有"**：DoD 写"四入口都在"，没写"第一眼看到什么"。

## 3 设计理念

# 一条路，一张纸，一个信号
### One route. One sheet. One signal.

- **一条路**：每屏只讲一条路由决策——目标 → 判据 → 出口 → 结果。这条"路"是全产品唯一的装饰几何：它出现在首屏、空态、加载、错误和图标里。
- **一张纸**：内容永远在纸面上；玻璃只给浮层（菜单栏面板、浮窗、命令面板、sheet）。每屏最多一个**墨色焦点带**。
- **一个信号**：朱红只标记"当前决策 / 正在生效 / 需要你处理"。其余状态色只做 6pt 圆点和文字，不做底色。

这句话同时解决了"没特色"和"堆砌"：特色来自重复出现的**一条路**，不是来自更多颜色或更多卡片。

## 4 七条不可妥协

1. **一屏一个焦点**：一个墨色焦点带（或一张主图/一条主曲线），其余全部安静。
2. **先构图后组件**：页头 / 焦点带 / 证据区，三段式；一屏一级模块 ≤5 个。
3. **字号先于颜色**：层级靠字号、留白、位置；颜色最后才用。正文 13，最小 11。
4. **密度分层**：常驻层 3 行、工作层中等、工具/收纳可以密；禁止全 App 统一 10pt。
5. **原生外壳，品牌内核**：窗口、侧栏、工具栏、控件行为按 macOS；品牌只放在"路"、图标、一句衬线。
6. **状态说人话**：一句事实 + 一个动作；不靠颜色单独表意（WCAG 1.4.1）。
7. **动效只讲因果**：换页、生效、回滚。hover 不做装饰动画。

## 6 视觉系统 v5

### 6.1 表面（只留三种）

| 名称 | Light | Dark | 用途 |
| --- | --- | --- | --- |
| paper | #F4EFE6 | #0F0F10 | 窗口底 |
| sheet | #FBF8F2 | #161618 | 内容纸面、行、输入 |
| ink | #19191B | #1C1C1F | **每屏一个**焦点带 |
| line | ink 10% | white 10% | 发丝线 |

删除：`cardTint` 叠玻璃、内容区 `lpGlass`、第二种深色卡。玻璃只用于 menu bar panel / floating / palette / sheet。

### 6.2 字阶（最小 11）

| 角色 | 字号/字重 | 说明 |
| --- | --- | --- |
| 页面标题 | 28 / semibold / -0.4 | 一页一个 |
| 区块标题 | 15 / semibold | 焦点带、模块 |
| 正文 | 13 / regular | 全 App 正文 |
| 次要 | 13 / secondary | 同字号，靠颜色 |
| 标签/眉标 | 11 / mono / +0.8 大写 | 每屏 ≤1 处 |
| 数字 | 20 / mono / semibold（主）/ 13（次） | tabular |
| 一句人话 | 15 / serif italic | 每屏 ≤1 句 |

删除 9pt/10pt 正文与 7pt 标签；mono 占比目标 <20%。

### 6.3 间距 / 圆角 / 网格

- 间距：4 / 8 / 12 / 16 / 24 / 32 / 48；页面 32；段间 24；模块内 16。
- 圆角：面板 12、控件 8、状态胶囊 full。统一，不再 6/10/16/20 混用。
- 网格：侧栏 240（折叠 64）；内容最大 1120；12 栏 / 24 gutter；证据区两栏（7+5）。
- 页头：标题+一句状态（左）｜1 主 + 2 次（右）；tab 作为页头下方的左对齐过滤条，不居中。

### 6.4 唯一的主色用法

- 朱红只出现在：当前节点、主按钮底、焦点环、正在生效的进度。
- 状态色只出现在 6pt 圆点 + 12pt 文字；不做底色、不做整行染色。
- 侧栏选中：ink 6% 底 + 2px 朱红左条 + 文字 primary；不再用浅朱红底。

## 7 构图模板（每页同一骨架）

```
┌ sidebar 240 ┬──────────────────────────────────────────────┐
│              │ 页面标题 28        状态一句 13     [主] [次] │
│              │ 一句人话 15 serif（可选，≤1）                 │
│              ├──────────────────────────────────────────────┤
│              │ 焦点带（ink，圆角 12，高 180–220）            │
│              │   一条路：你 ── 规则 3 ── 公司 · HK 01        │
│              │   四个事实（20 mono）+ 一个主操作              │
│              ├──────────────────────────────────────────────┤
│              │ 证据区：两栏（7/5），每块只做一件事             │
│              └──────────────────────────────────────────────┘
```

模块预算：页头 1 + 焦点带 1 + 证据区 ≤2 + 可选页脚 1 = **≤5 个一级模块**。

## 8 交互规范

- **四动词**：进入页面先给"当前答案"，再给"证据"，最后才是"改"；改完原地出结果（S2）。
- **常驻层**：3 行（现在/切换/异常），280 宽；与首屏共用同一条"路"的缩略版。
- **空态**：一句事实 + 一个示例 chip + 一个动作；禁止在空态里放大号橙色按钮。
- **错误**：一句人话 + 原因 + 一个动作 + 可关闭；颜色只做辅助。
- **键盘**：⌘1–4 动词、⌘K 命令面板、Esc 返回、Tab 焦点环可见；所有行可键盘到达。
- **动效**：换页 180ms ease-out（位移 4pt + 淡入）；生效 120ms；回滚 200ms；reduce motion 时全关。

## 9 逐页方案

| 页面 | 现在 | v5 |
| --- | --- | --- |
| 走哪 | 6 张场景卡 + 2 个深色大卡 + 3 个快捷按钮 | 焦点带＝一条路（你→规则→出口）+ 四个事实；下面 3 条最近决策 + 场景 chips；删掉大卡 |
| 怎么判 | 规则表 + 策略组混排 | 表为主；页头搜索/过滤 chips；策略组右栏可折叠；行 hover 才出动作 |
| 改成什么 | 四 tab 居中 + 编辑器 | 页头左侧过滤条（重写/Mock/脚本/去广告）+ 单一"新建"主按钮 + 列表；编辑器为 sheet |
| 为什么 | 居中 tab + 空态大按钮 | 查询条 + 垂直 trace（同一"路"竖过来）+ 右侧详情；空态示例 chips |
| 工具/收纳 | 自绘卡片 | macOS 表单/列表原生；不做 hero |
| 菜单栏 | 三块 + chips | 280 宽，"路"缩略 + 3 行；异常块只在有事时出现 |
| 浮窗 | 速率 + 最近 | 速率 + 一条路缩略 + 最近 2 条 |

## 10 矛盾裁决（自己解决，不留给用户）

| 矛盾 | 裁决 |
| --- | --- |
| 专业密度 vs 可读性 | 分层密度：常驻层 3 行、工作层中等、工具/收纳密；正文永远 13 |
| 品牌个性 vs macOS 原生 | 外壳原生；个性集中在"一条路"+图标+一句衬线 |
| 暖纸 vs 深色卡 | 一屏最多一个 ink 焦点带；其余纸面 |
| Liquid Glass vs 纸 | 玻璃只给浮层；内容区禁止 |
| 四动词 vs 工具/收纳 | 侧栏分组；页面内不重复四动词入口 |
| 信息完整 vs 留白 | 每屏一个问题；其余进"更多"或详情 |
| 动效 vs 性能 | 只做因果三件；reduce motion 全关 |
| 个性 vs 可维护 | 一个签名组件（RouteLine），token 化，不允许每页自造 |

## 11 迭代路线

| 波次 | 内容 | 验收 |
| --- | --- | --- |
| W1 基础（T-15） | Theme v5 token、字号/间距、去内容区玻璃、页头组件、侧栏选中态、模块预算 | 5 屏截图；无 <11pt；AA；一屏 ≤1 主按钮 |
| W2 四动词（T-16..T-19） | 走哪 / 怎么判 / 改成什么 / 为什么 按模板重排；RouteLine 组件 | 每页 3 秒测试；截图 diff |
| W3 品牌（T-20） | 菜单栏/浮窗、空态、图标、onboarding、动效 | 同一"路"在 5 处出现；reduce motion 通过 |

设计任务不改变 M2 的功能 DoD；它只改"怎么摆"。W1 先做 token 与页头，避免 W2 重复改。

## 12 验收（可测）

1. 每屏 ≤1 个 ink 焦点带、≤1 个填充主按钮、≤5 个一级模块。
2. 最小字号 11；正文 13；mono 只用于数字/ID。
3. 对比度 AA；焦点环可见；点击目标 ≥24pt。
4. 3 秒测试：5 人里 ≥4 人能说出"这页干什么、该点哪"。
5. 页面轴线 ≤2（左对齐 + 右侧动作）；无居中悬浮 tab。
6. 组件预算：每页只用 PageHeader / FocusBand / Module / Row 四件。
7. 同一"路"在首屏、为什么、空态、菜单栏、图标五处出现。

## 13 风险

- **改版成本**：W2 会动 4 个页面；用 W1 的 token 与模板减少返工。
- **品牌过弱**：如果"一条路"不够显眼，优先加强它在焦点带与图标中的存在，不加新颜色。
- **原生 vs 特色**：所有自绘控件先问"系统有没有"；没有才自绘。

## 14 竞品参考与流程修复

你之前给过的竞品截图**没有留在仓库里**（`docs/` 下只有我们自己的产品截图），所以这次无法逐张对照——这是流程问题，不是素材问题。修复：

1. 新建 `docs/refs/<产品名>/`，截图原图入库；每张图旁边一页 `notes.md`，只写四件事：**第一眼落在哪 / 字号与密度 / 留白节奏 / 一个可借的构图**。不写功能清单。
2. 每个设计波次开始前，做一次 10 分钟 teardown，产出一页"借什么、不借什么"。
3. 竞品分三类，各借一件事：
   - 专业代理客户端（Surge / ClashX 类）：**表格密度与状态点**，不借它们的多层弹窗。
   - 抓包检查器（Proxyman / Charles 类）：**左列表右详情的分栏与时间线**，不借它们的工具栏堆叠。
   - 命令面板工具（Raycast 类）：**键盘优先与单一焦点**，不借它们的卡片墙。
4. 把截图放回 `docs/refs/` 后，我做第二轮逐张对照，并把结论补进本文件。
