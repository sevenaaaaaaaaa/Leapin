## 1 产品目的

### 1.1 一句话

**Leapin 是一个网络配置工作台：你说哪条流量走哪条路，它替你执行；没按你说的走时，它告诉你为什么。**

不开代理机场的店，不做抓包工具的皮。它的产品本体是**一条路由决策**：目标 → 路 → 生没生效。

### 1.2 要解决的问题

在 Mac 上工作的人，每天要回答同一个问题的四个变体：

| 变体 | 用户的原话 | 今天要在几个工具之间来回 |
| --- | --- | --- |
| 走哪 | 让这个服务走海外 / 走公司 / 直连 | 代理客户端 + 系统设置 + 公司 VPN |
| 为什么没走成 | 这网站怎么打不开，是没命中规则还是 DNS 脏了 | 客户端日志 + `dig` + 抓包 |
| 改成什么 | 把这个接口的返回改掉，或者 mock 一下 | Charles / Proxyman / DevTools |
| 一套配置跟着我 | 在公司、在家、在机场，别让我重配一遍 | 手动改 + 记忆 |

四件事共享一个前提：**这台机器现在到底怎么走的**。今天这个前提要在四个工具里各查一遍，每次切换都重建一次上下文。

### 1.3 它不是什么

- **不是另一个 Clash 客户端**：订阅与节点是输入，不是产品。产品的价值在决策与验证。
- **不是抓包工具**：抓包是"验证"的手段。把它当本体，就会做成 Proxyman 的劣化版。
- **不是 VPN 套壳**：连内网是"路"的一种，不是另一个 App。

### 1.4 五个场景（谁在什么时刻打开它）

| # | 场景 | 时长 | 接触面 |
| --- | --- | --- | --- |
| S1 | 早上开工：看一眼现在走哪条 → 今天要连公司，切场景 → 关窗 | 30 秒 | 菜单栏 |
| S2 | 某站点打不开：输入域名 → 看命中链与出口 → 就地换路 → 立即重测 | 90 秒 | 窗口·为什么 |
| S3 | 联调接口：加一条重写 → 用真实请求验证 → 导出 HAR | 5 分钟 | 窗口·改成什么 |
| S4 | 回到家：切"家里" → Tailscale 资源直连 | 20 秒 | 菜单栏 |
| S5 | 挂着：一整天不打开；出问题时菜单栏变红 | 0 秒 | 菜单栏 / 浮窗 |

**四个场景在两分钟内结束，一个零操作。这就是产品的形状：短、准、可关闭。**

### 1.5 现状（v1.13.13）与差距

v1.13.x 已经把视觉收干净了（三轮评审 6.7 → 7.20，Color 与 Originality 过 8.0 线）：字号收敛到 17 档、单信号色、地震仪、隐私改「—」。**现在的问题不在皮肤，在骨架。**

| 事实 | 差距 |
| --- | --- |
| mac 19 个页面、手机 5 个 tab | 按「功能」切，不按「用户带着的问题」切。四个动词散在 8 页里 |
| 总览首屏已讲「现在」（hero + 统计条 + 地震仪 + 最近连接） | 但它讲的是**仪表**，不是**四个动词的入口**。用户看完仍不知道该点哪 |
| 菜单栏面板 + 浮窗已存在 | 只当状态显示器，没承担 99% 的接触时间 |
| iOS 5 tab 以「工具」为首（已避免死路在配对屏） | 语义仍是「Mac 的控制台」，不是「这台手机上的网络」 |
| 能力：导入 / 理解 / 分流 / 改写 / 验证 / 回滚都已建 | 缺「接管」这一环（见 §2.5 诚实条款）——不守系统代理的进程会直接绕过 |

## 2 它必须做到什么

### 2.1 三层结构

按**接触频率**分层，这是信息架构的第一刀：

| 层 | 频率 | 承担 | 判定标准 |
| --- | --- | --- | --- |
| **常驻层** | 99% 时间，窗口关着 | 现在走哪条路 · 一键切换 · 只在异常时说话 | 三级信息：图标（墨/红）→ 面板（路 + 速率）→ 浮窗（明细）。不打开窗口也能完成 S1 / S4 / S5 |
| **工作层** | 需要改配置时 | 四个动词 | 入口按问题分；任一视图可跳到另一视图且带上下文 |
| **工具层** | 偶尔，与主线无关 | SSH · NAS · 回家 · 公司内网 · 分享本地服务 | 不与四动词并列；从侧栏独立分组进入 |
| **收纳层** | 用户不主动来 | 导入 · 书签 · 智能学习 · 设置 · 内核管理 | 可搜、可达、但不占首屏 |

### 2.2 四个动词

工作层只有一个对象：**一条路由决策**。四个动词是它的四种操作。

| 动词 | 用户的问题 | 视图 | 动作 | 如何验证 |
| --- | --- | --- | --- | --- |
| **走哪** | 让 X 走 Y | 当前决策总览（配置 / 场景 / 出口 / 最近决策） | 选目标 → 选路 → 立即生效 | 生效即刷新，无需重载 |
| **怎么判** | 规则为什么这样定 | 规则 + 策略组 + 诊断（永不命中 / 被遮蔽） | 增删改一条规则 | 行内预检 + 命中计数 |
| **改成什么** | 把请求 / 响应改掉 | 重写 + Mock + 脚本 + 去广告（同一引擎） | 新建一条改写规则 | 抓包看改动前后 |
| **为什么** | 它为什么没走成 | 诊断 + 抓包 + DNS trace + 探测 | 输入一个目标 | 命中链 + 每跳耗时 |

**硬规则：四个动词共享同一份上下文。** 在「为什么」里查到某条连接，可以直接「就地改路」生成规则（已有临时规则的雏形）；在「怎么判」里改完规则，可以立刻跳到「为什么」重测同一个主机。今天的四页之间没有这条跳转。

### 2.3 页面去留（19 → 12）

| 现状 | 去留 | 归属 |
| --- | --- | --- |
| Dashboard（总览） | **重写** | 走哪 · 首屏 = 当前配置 + 当前出口 + 地震仪 + 最近决策 3 行 + 四个动词入口 |
| Profiles（订阅 / 配置） | 保留 | 走哪 · 配置列表 |
| Rules（规则 / 策略组） | 保留 | 怎么判 |

| AdBlock（去广告） | **并入** | 改成什么（它就是声明式改写的一种） |
| Capture（抓包） | 保留 | 为什么 |
| Observation（观测） | **并入** | 为什么（实时指标并入诊断页头） |
| NetworkTools（网络工具） | **并入** | 为什么（探测是诊断动作） |

### 2.4 iOS 的角色

不做假的接管，做三件真的事：

| 角色 | 内容 | 依赖 |
| --- | --- | --- |
| **本机可用** | 引擎跑在手机上（M1 已验证）+ 把 Wi-Fi 代理指向 127.0.0.1 的一步引导 + 自检 | 无 |
| **遥控** | Mac 在线时，完整控制面（现在已有） | Mac 可达 |
| **下游** | 配置 / 规则 / 出口从 Mac 同步下来，离线用本地快照 | 同步 |

**首页语义从「控制台」改成「这台手机上的网络」**：本机引擎开没开、有没有被系统使用（能检测到就显示，检测不到就给一步引导）、Mac 在不在线。原「状态」tab 的 Mac 快照降为第二张卡。

**不做**：不做系统接管（无 NE entitlement），不做"VPN 已连接"的假状态，不以 Mac 为运行前提。

### 2.5 诚实条款（必须写进 App，不是写进文档）

这一轮不做第 5 环（接管）。因此：

> **Leapin 只能管住愿意走系统代理的进程。** Docker、部分命令行工具、部分 Electron App 会绕过它。

这条必须出现在**总览首屏**，以一行事实呈现（不是免责声明）：`接管范围：系统代理 · 有 N 个进程未覆盖`。能检测就报数，不能检测就写「部分进程未覆盖」。用户撞上去之前就知道，比事后猜更值钱。

### 2.6 不在这一轮的范围

| 不做 | 原因 | 什么时候 |
| --- | --- | --- |
| TUN / NetworkExtension / 特权 helper | 用户选择"先把能力做深"，不投签名与分发 | 下一轮决策 |
| pcap · 代理链 · 混合网络 · 热点 | 依赖 TUN | 同上 |
| 商业化 · 签名 · 公证 · 商店 | 受众未定 | 同上 |
| tvOS · 小组件 | 需要先迁 Xcode 工程 | 同上 |
| 脚本编辑器 | 能力已有，界面后补 | 后续版本 |

### 2.7 优先级

| 级 | 项 |
| --- | --- |
| **must-have** | 1. 常驻层成为产品主入口（菜单栏三级信息 + 一键切）<br>2. 工作层四动词重组（19 → 4 动词 + 工具 + 收纳）<br>3. 路由决策对象统一（四视图可互跳并带上下文）<br>4. 接管边界显式化（§2.5） |
| **high-want** | 5. iOS 首页语义改为「这台手机上的网络」<br>6. 地震仪推广到「改成什么」与「为什么」 |
| **nice-to-have** | 7. 书签 / 学习并入收纳层<br>8. 隐私页删除后的事实迁移 |

必须项没做完不发版。

## 3 验收标准（Release criteria）

| 维度 | 标准 | 怎么判 |
| --- | --- | --- |
| 性能 | 首屏 < 300ms；切换场景 / 出口 < 1s；10 万规则 p95 仍 < 2ms | 现有 benchmark + 新增首屏测量 |
| 可用性 | S1 / S4 在菜单栏 ≤30s 完成；S2 ≤90s；S5 零操作 | 录屏走一遍，计时 |
| 可靠性 | 声明不得声称覆盖全部流量；有检测能力时报出具体数量；崩溃后系统代理不残留 | 现有原子回滚测试 + 新增边界检测测试 |
| 可溯源性 | 任一数字可点开看到来源连接 | 抽查 5 个数字 |
| 可支持性 | 每个动作可在 CLI 找到等价命令 | `leapin --help` 对照 |
| 本地化 | 中英双语；不做其他语言 | 本期不做 |
| 无障碍 | 键盘可达全部动词页；reduce motion 覆盖 100% | Tab 走查 |

## 4 里程碑

每个里程碑都能单独看、单独否。

### M1 · 常驻层（PoC，最薄真实路径）

**目标**：不打开窗口也能完成 S1。菜单栏显示真实的路由决策，一键切换真的生效。

**用户怎么试**：点菜单栏图标 → 看到「当前：海外 · 3 条规则命中 · ↓1.2M/s」→ 点「公司」→ 一秒内系统代理指向公司配置 → 打开浏览器访问内网地址通了。

**DoD**
1. 菜单栏图标能区分三种状态：正常（墨）/ 降级（半红）/ 异常（红），且由真实引擎事件驱动，不是定时轮询。
2. 面板显示：当前配置名、当前出口、最近 60s 速率、被拦截数；数字与窗口内一致。
3. 一键切换配置 / 场景，1 秒内生效，且失败时回滚并给出原因。
4. 浮窗与菜单栏读同一份状态，不出现两个数字。
5. 关窗状态下连续运行 8 小时，RSS 不增长超过 20MB。

### M2 · 工作层四动词

**目标**：19 页收成 4 个动词 + 工具 + 收纳，四个视图之间带上下文互跳。

**用户怎么试 S2**：打开「为什么」→ 输入 `api.company.com` → 看到命中第 3 条规则、走 DIRECT、耗时 40ms → 点「改成走公司」→ 立刻生成一条精确规则并在原地重测 → 通了。

**DoD**
1. 侧栏只有 4 个动词入口 + 工具分组 + 收纳分组，行数 ≤ 11。
2. 总览首屏包含四个动词的入口，且每个入口带当前状态（不是纯按钮）。
3. 「为什么」里任一连接可一键生成规则 / 临时规则，生成后原地重测。
4. 「怎么判」改完规则后可直接跳到「为什么」并带上同一主机。
5. 「改成什么」里重写 / Mock / 脚本 / 去广告共用一套列表与生效路径。
6. 被合并或删除的 5 页（Observation / NetworkTools / DiagnosticReport / AdBlock / Privacy）能力无丢失：每项能力都能在新位置找到，并有一张迁移对照表；删除的页面须说明其事实搬到了哪里。
7. 接管范围一行事实出现在首屏（§2.5）。

### M3 · iOS 语义

**目标**：首页从「Mac 控制台」变成「这台手机上的网络」，且不装接管。

**用户怎么试**：手机不连 Mac 打开 App → 看到本机引擎开着、端口 51003、自检通过 → 点「把这台手机的 Wi-Fi 代理指过来」→ 照一步引导做完 → Safari 访问 example.com，工具页显示这条请求经过本机引擎。

**DoD**
1. 首页第一屏回答三个问题：本机引擎开没开、有没有被系统使用、Mac 在不在线。
2. Mac 未配对时首页可用（不是空态 + 配对按钮）。
3. 未配对时的「策略 / 连接 / 诊断」页给出明确原因与替代动作，不停在空白。
4. 不存在任何暗示"VPN 已连接"的文案或状态。
5. 首页与 Mac 端对同一配置的命名一致。

## 6 风险

1. **重排会不会变成"重写一遍 UI"**：会。19 页里 11 页要动。缓解：M1 先只做常驻层，验证方向再动工作层。
2. **并入会丢能力**：AdBlock / Observation / NetworkTools 里有真实能力（命中测试、实时指标、HTTP 探测）。缓解：M2 的 DoD 第 6 条强制迁移对照表。
3. **常驻层做重了会变成第二个窗口**：菜单栏面板一旦能装下四个动词，就退化成了小窗口。缓解：常驻层只允许三个动作（看、切、跳），任何编辑动作都打开窗口。
4. **接管边界写出来会显得产品不完整**：会。但比用户撞上后才发现强。这条是产品诚实性的底线，不因观感让步。
5. **iOS 改了首页但没人用**：iOS 现在没有真实用户。缓解：M3 的验收以"不连 Mac 也能用"为准，不以"有人用"为准。
